- Metadata、任務表及驗證紀錄採用 [文件規範附錄 E](../AGENTS.md#附錄-etask-範本)。
- 新增前檢查本目錄與 [§10 索引](../AGENTS.md#10-索引)，確認日期、流水號及關聯，以 `draft` 建立並同步索引。
- 文件狀態與個別任務狀態分開，依 [§14](../AGENTS.md#14-task開發任務) 使用；不得自創狀態。
- 驗證記錄須包含可核對的執行方式、結果與範圍；未執行須註明原因，不得宣稱通過。
- 核准與完成條件依 [文件治理正本](../AGENTS.md)；TASK 完成不代表所有關聯需求完成。

# 公司形象網站功能規格

## 1. 功能目的

依 [已核准 REQ](../req/20261019-0001-company-website.md) 建立「澄岳數位設計／Chengyue Digital Design」三頁雙語形象網站，以清楚的業務資訊、公司背景與可操作的動畫互動呈現虛構公司。品牌文案與風格引用 REQ §6，不重複維護。

本文件已依使用者於 2026-10-19「確認 SPEC，進入 DESIGN」核准，以下路徑與互動行為為設計依據；不代表網站已實作或 DESIGN 已核准。

## 2. 主要行為

| 範圍 | 預期行為 |
|------|----------|
| F01 首頁 | 包含品牌主視覺、主標與摘要、三項業務摘要、公司簡介及前往另兩頁的入口；品牌標誌可回首頁。 |
| F02 業務服務 | 原稱公司介紹，對外導覽與標題改用「業務服務／Services」。介紹品牌視覺、企業網站、數位介面三項業務；預設顯示第一項，選取其他業務時更新對應說明並清楚標示選取項，不離開當頁。 |
| F03 關於公司 | 顯示公司簡介、示範地址及團隊起步／服務拓展／持續深化三項經歷；經歷預設收合，可獨立展開或收合，多項可同時展開。 |
| 共用導覽 | 三頁都有首頁／Home、業務服務／Services、關於公司／About 入口、目前頁面識別、語言切換及頁尾；行動版導覽可開啟、關閉並選取頁面。 |
| F04 語言 | 支援繁體中文 zh-TW、英文 en，使用 next-intl；預設繁體中文。三頁內容、導覽、互動文字、示範標示及頁面標題均有等義翻譯，保留品牌名稱等專有名詞。 |
| 語言切換 | 切換至相同內容頁的另一語言，不一律回首頁；目標網址直接開啟或重新整理仍顯示網址指定的語言。業務選取與經歷展開可重設為預設狀態，不要求跨語言保存。 |
| 路徑方案 | 首頁 /zh-TW/、/en/；公司介紹 /zh-TW/services/、/en/services/；關於公司 /zh-TW/about/、/en/about/。GitHub 專案站全部路徑須加部署基底 /儲存庫名稱，使用者站則無此前綴。站點入口以瀏覽器導向繁體中文首頁並提供可直接點擊的備援連結，不依賴伺服器重新導向；不支援語言或未知內容為 404。 |
| 全新入口 | 以全新的形象網站取代既有練習首頁，不保留練習功能、/practice 獨立入口或通往練習內容的導覽；根路徑依上述方案導向繁體中文首頁。 |
| 操作回饋 | 導覽、按鈕、語言切換、業務切換與經歷展開皆有可辨識的焦點／操作狀態；不能只依滑鼠 hover 才能取得內容。 |
| 動畫 | 三頁主要內容有進場動畫；業務切換與經歷展開有操作觸發動畫。動畫過程仍可閱讀、操作與離開頁面，不強迫觀看完畢。 |
| UI／UX 與動態風格 | 以具有辨識性的品牌視覺與動態語言整合首頁主視覺、資訊層級、導覽及內容互動。各頁保持一致的操作邏輯與視覺節奏，不能只用通用淡入或堆疊裝飾特效滿足「特別」的要求。 |
| 手機與鍵盤 | 手機可讀取完整內容及完成上述操作；鍵盤可循序到達所有互動項目，啟用、切換及收合，不因導覽或動畫而失去操作位置或陷入無法離開的區域。 |
| 手機與減少動態 | 手機保留同源視覺語言，降低同時運動元素，不將桌面動畫等比例縮小代替適配；減少動態效果偏好下取消非必要位移、描繪及錯開，內容與操作能力不減少。 |

## 3. 重要限制

- 保留三個獨立內容頁，不能以單頁三區塊、空白頁或重複文案替代；兩語資訊與主要操作能力一致。
- 無後台、會員、購物車、資料庫、CMS、寄信表單或流量追蹤；以 GitHub Pages 靜態部署及公開 HTTPS 瀏覽為交付，不選購網域或付費服務。公司業務介紹不代表要實作對應服務系統。
- 全站由建置產生靜態檔，動畫及互動在瀏覽器執行；不要求訪客啟動本機服務，不依賴執行期 Node.js、Proxy、伺服器重新導向或動態 API。網站以 HTTP／HTTPS 存取，不以雙擊 file:// 檔案作為交付方式。
- 網站須明示虛構示範；地址採 REQ 已確認的「示範地址，無實體營業據點」及等義英文，不提供誤導性的真實門牌、客戶、獎項或績效。
- 缺少翻譯不得把原始翻譯鍵或混合語言當成正常交付；DESIGN 須定義缺漏處理及確認兩語內容完整的方式。
- 中文與英文須同步進行版面及動態設計，英文長文案不得被裁切或以任意縮小字體處理；風格樣稿應包含兩語與手機狀態。
- 動畫不能遮蔽必要資訊、阻擋導覽或成為操作前提；具體效果、時間、減少動態效果偏好及驗證環境依既有前端規範與後續 DESIGN 展開。
- 動畫存在與設計品質須分別確認；後續 DESIGN 須提供可檢視的 UI／UX 與動態方案，說明獨特表現如何服務品牌、閱讀及操作，再確認具體風格。不得僅憑特效數量或單一淡入效果認定風格要求已滿足。
- 實際路由盤點、舊練習程式替換與清理範圍、套件版本、相容性及 Server／Client 邊界留待 DESIGN 查證；不得因取消練習需求而刪除仍供新網站使用的共用檔案或使用者其他變更。

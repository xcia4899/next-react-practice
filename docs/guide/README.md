# GUIDE：正式使用指南

只記錄已實現且經驗證的正式用法，不把規劃或草稿寫成可用功能。

- 檔名採英文小寫主題 slug，例如 `product-search.md`；不使用文件 ID、流水號或狀態生命週期。
- 正文採用 [文件規範附錄 F](../AGENTS.md#附錄-fguide-範本)，責任見 [§15](../AGENTS.md#15-guide正式使用指南)。
- 建立前查找既有指南與 [§10 索引](../AGENTS.md#10-索引)，確認用法已有驗證證據；關聯只引用真實文件。
- 公開 API、設定或正式操作方式改變時，檢查指南並同步受影響內容；新增或更名須更新索引。
- 文件治理依 [正本](../AGENTS.md)。

目前未建立正式 GUIDE。舊路徑 `docs/guides/` 的文件不因本目錄建立而自動成為正式指南。

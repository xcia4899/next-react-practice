# ADR：架構決策

記錄需要長期維護的重要決策、替代方案、原因與影響；單一設計中的小問題留在 DESIGN。

- 檔名：`YYYYMMDD-NNNN-kebab-case.md`；ID：`ADR-YYYYMMDD-NNNN`。
- Metadata 與正文採用 [文件規範附錄 B](../AGENTS.md#附錄-badr-範本)，決策規則見 [§7](../AGENTS.md#7-adr-格式)。
- 新增前檢查本目錄與 [§10 索引](../AGENTS.md#10-索引)，確認日期、流水號及關聯，以 `proposed` 建立並同步索引。
- 尚未決定時，「決策」「選擇原因」寫「待決定」；AI 不得自行標記 `accepted`。
- 修訂或取代已接受決策時，依 [文件治理正本](../AGENTS.md) 保留確認來源及歷史。
